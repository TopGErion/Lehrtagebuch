## 1. Was ist ein ERD?

Ein ERD ist eine grafische Darstellung einer Datenbank. Es zeigt, welche Daten gespeichert werden, welche Eigenschaften sie haben und wie die einzelnen Elemente miteinander verbunden sind.

---


## 2. Bestandteile eines ERD

- Entities: Ein Objekt oder eine Person, über die Daten gespeichert werden.

- Attributes: Ein Attribute beschreibt eine Eigenschaft einer Entität.

- Relationship: Eine Beziehung zeigt, wie zwei Entitäten miteinander verbunden sind.

---

## 3. Beispiele für ein ERD

- Ein Schüler besitzt eine Schüler-ID und einen Namen.

- Ein Kurs besitzt eine Kurs-ID und ein Ort.

- Ein Schüler kann mehrere Kurse besuchen und ein Kurs kann von mehreren Schülern besucht werden.
